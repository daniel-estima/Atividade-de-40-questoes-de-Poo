# Lista de Exercícios em Java ☕

Repositório contendo a resolução de 40 exercícios práticos em Java, focados na consolidação de conceitos fundamentais de programação e lógica.

## 📌 Conteúdos Abordados

* **Estruturas de Repetição:** `for`, `while`, `do-while`
* **Estruturas Condicionais:** `if-else`, `switch-case`
* **Manipulação de Dados:** Tipos primitivos, operações matemáticas e tratamento de entradas com `Scanner`
* **Algoritmos Clássicos:**
  * Calculadora e operações bancárias
  * Sequência de Fibonacci e Collatz
  * Verificação de números primos, perfeitos, Armstrong e palíndromos
  * Algoritmo de Euclides (MDC e MMC)
  * Manipulação de Strings e jogos simples
